# Подключение проекта

Каждый проект — папка `projects/<folder>/` с `project.mjs`, CSS и собственными ресурсами
Пути относительны к этой папке, абсолютные пути к компьютеру не нужны

## Минимальный контракт

```js
export default {
  id: 'my-project', name: 'Мой проект', revision: 1,
  styles: 'site.css', assets: {logo: 'assets/logo.svg'},
  sections: [{id: 'hero', label: 'Первый экран'}],
  tokens: {paper: '#fff'},
  decisions: [{
    id: 'accent', group: 'Общий дизайн', label: 'Акцент',
    default: 'blue', targets: ['hero'],
    variants: [
      {id: 'blue', label: 'Синий', description: 'Спокойный', tokens: {accent: '#245baa'}},
      {id: 'green', label: 'Зелёный', description: 'Природный', tokens: {accent: '#286447'}}
    ]
  }],
  presets: [{id: 'original', label: 'Исходный', state: {}}],
  content: {title: 'Ваш заголовок'},
  notes: ['Описание текущих продуктовых ограничений'],
  render: function ({tokens, content, assets, escapeHTML: e}) {
    return `<main id="hero" style="color:${e(tokens.accent)}">
      <img src="${assets.logo}" alt="Логотип">
      <h1>${e(content.title)}</h1>
    </main>`
  }
}
```

## Правила

- `id` проекта, секций, решений, вариантов и пресетов: латинские буквы, цифры и дефис, первый символ — буква
- `id` решений уникальны, `default` обязан указывать на существующий вариант
- `targets` ссылается на существующие секции, в HTML должны быть элементы с соответствующими `id`
- `tokens` выбранных вариантов объединяются по порядку решений поверх исходных токенов
- Если разные решения задают один токен, побеждает последнее — лучше избегать неявных конфликтов
- Пресет содержит частичные `state`-переопределения, остальные значения берутся из `default`
- `sample` у варианта задаёт короткую подпись его мини-превью
- `viewports: {desktop: 1280, mobile: 390}` можно переопределить
- `revision` повышается при несовместимом изменении решений, старые JSON не импортируются молча
- `content` и `notes` должны быть JSON-совместимыми данными
- `render`, необязательные `preview` и `runtime` должны быть самостоятельными `function (...) { ... }`, без внешних импортов, замыканий и переменных модуля
- `render` получает `{state, tokens, content, assets, escapeHTML}`, используй `escapeHTML` для текста и атрибутов
- `preview` получает `{decision, variant, state, tokens, escapeHTML}` и возвращает HTML миниатюры варианта — токены уже учитывают именно этот вариант, без `preview` используется подпись `sample`
- `runtime` получает `{state, tokens}`, запускается один раз внутри нового iframe при каждом выборе
- Собственные обработчики должны уважать клавиатуру и reduced motion

Адаптер не является готовым React/Next-приложением — это автономное HTML/CSS/JS-превью
Сложный сайт можно представить выбранными экранами, затем перенести утверждённый вариант в его основной стек

## Ресурсы и шрифты

Объяви файл в `assets`, используй `assets.<name>` в `render` — сборщик подставит data URI
Поддерживаются SVG, PNG, JPG, WebP, GIF, WOFF2 и TTF
Файлы за пределами папки проекта отклоняются, включая переходы через `..` и symlink

Для ресурса в CSS используй `url(asset:имя)`

```css
@font-face {
  font-family: ProjectFont;
  src: url(asset:fontRegular) format('woff2');
  font-display: swap;
}
```

Сохраняй лицензии сторонних шрифтов и изображений рядом с материалами
Для автономного HTML не добавляй CDN, удалённые картинки или относительные `src` вручную
Внешние переходы открывай через `target="_blank" rel="noopener noreferrer"`
Превью изолировано в sandbox iframe — формы, навигация родительской страницы и доступ к её хранилищу заблокированы

## Выбор и экспорт

JSON: `schemaVersion`, `project.id/revision`, `designState`, выбранные решения, итоговые токены, контент и примечания
При импорте используются только `designState` и идентификатор/редакция проекта, дополнительные экспортированные данные не исполняются
Ошибочный импорт сохраняет предыдущий выбор
Хранилище браузера разделено ключом `design-configurator:<id>:<revision>`
Экспорт HTML пересобирает именно текущий выбор, исходники шаблона в него не входят

## Проверка

Запусти `npm test` и `npm run build -- --project my-project`
Добавь новый проект в тест комбинаций или отдельную проверку его адаптера
Проверь выбранные варианты, мобильную ширину, разделитель, импорт после сброса и скачанный HTML без сети
