# Design Configurator

Личная студия выбора дизайна для разных проектов
Слева — решения и варианты, справа — настоящий адаптивный сайт
Оболочка перенесена из конфигуратора Клавы, материалы и продуктовая логика отделены от неё

## Быстрый старт

Нужен Node.js 22 или новее, устанавливать npm-зависимости не требуется

```sh
npm run dev
```

Открой `http://127.0.0.1:4180`, сервер доступен только на твоём компьютере
Изменения в `core/` и папке выбранного проекта пересобираются автоматически — обнови страницу браузера
Разные проекты можно запускать параллельно на разных портах, их dev-сборки изолированы в `.dev/`

```sh
npm run dev -- --project workshop --port 4181
npm run build -- --project starter
npm test
```

Сборка создаёт три файла в `dist/`

| Файл | Содержимое |
| --- | --- |
| `index.html` | Весь конфигуратор с материалами внутри |
| `site.html` | Сайт с исходным выбором и полоской Desktop / Mobile |
| `selection.json` | Исходный выбор в переносимом формате |

HTML-файлы можно открыть двойным кликом или передать отдельно, сеть для примеров не нужна
Команда сборки перезаписывает `dist/`, выбранный в браузере вариант сохраняй кнопкой «Экспорт выбора»
Сохранение в браузере может быть недоступно в некоторых режимах `file://`, для надёжной работы используй `npm run dev`

## Что умеет оболочка

- Произвольные группы решений и любое количество вариантов от двух
- Пресеты, сравнение исходного и выбранного состояния
- Разделитель панелей с мышью, touch и стрелками клавиатуры
- Масштабирование только сайта, просмотр по ширине или целиком
- Desktop / Mobile, мобильное переключение между пикером и превью
- Светлая и тёмная темы инструмента, независимые от темы сайта
- Сохранение отдельно для каждого `id` и `revision` проекта
- Экспорт выбранных параметров в JSON, текстовую спецификацию и автономный HTML
- Импорт JSON с проверкой проекта, версии и доступных вариантов
- Управление вариантами стрелками, Home и End, видимый фокус и reduced motion

Экспорт всегда использует выбранные параметры, даже когда в превью включено «Было»
Экспортированный HTML содержит только сайт и переключатель Desktop / Mobile
Это инструмент проектирования — перенос выбранного решения в production-приложение остаётся отдельным этапом

## Новый проект

1. Создай репозиторий через **Use this template → Create a new repository** на GitHub
2. Скопируй `projects/starter/` в `projects/my-project/`
3. Измени `id`, название, контент, решения и функцию `render` в `project.mjs`
4. Подготовь `site.css` и материалы в `assets/`
5. Запусти `npm run dev -- --project my-project`
6. Выбери дизайн и сохрани JSON вместе с проектом

Варианты должны менять настоящий сайт — добавление карточки в пикер само по себе не реализует её визуальный эффект
Подробный контракт и примеры — [PROJECT-GUIDE.md](PROJECT-GUIDE.md)
Инструкции для Codex — [AGENTS.md](AGENTS.md)

Для нового чата можно написать

> Используй Design Configurator из этого репозитория для моего проекта
> Сохрани оболочку, создай отдельную папку проекта, подключи мои материалы и предложи варианты решений
> Первый вариант каждого решения должен соответствовать моему исходному макету

## Организация

`core/` — универсальные интерфейс, состояние и экспорт
`projects/starter/` — пример продуктовой страницы Forma
`projects/workshop/` — независимая афиша с интерактивным раскрытием, двумя секциями и 2/4 вариантами
`scripts/` — сборка без внешних пакетов и локальный сервер
`tests/` — комбинации, переносимость, импорт и автономный экспорт

Примеры не содержат реальных заявок, платежей, пользовательских данных или внешних API
Код адаптера проекта выполняется при сборке и в превью — подключай только доверенные адаптеры
JSON импорта содержит только выбор, не исполняемый код
Приватный репозиторий и созданные из него проекты можно развивать независимо, обновления оболочки между копиями переносятся вручную
