# Проверка шаблона

Проверено 6 октября 2026

- `npm run check`: пять проверок Node.js и автономная сборка
- 72 комбинации starter и 8 комбинаций workshop дают 80 разных результатов renderer
- Экспортируемые токены совпадают с выбором, JSON проходит обратный импорт
- Неизвестные решения, отсутствующие поля, другой проект и редакция отклоняются
- HTML-границы script экранируются, ресурсы примеров встроены, локальных абсолютных путей в сборке нет
- В браузере проверены произвольное число вариантов, End, разделитель с клавиатуры, масштаб всего сайта и Desktop/Mobile
- Выбраны синий акцент и редакционный ритм, включено «Было» — экспорт сохранил выбранный синий вариант
- После сброса импорт JSON восстановил цвет и ритм в реальном превью
- На ширине 390 px панели переключаются и горизонтального переполнения оболочки нет
- Второй проект запускается одновременно на другом порту, не заменяя первый
- В автономном HTML второго проекта работают Mobile и интерактивное раскрытие
- HTML, скачанный кнопкой экспорта, найден в Downloads и проверен отдельно

Проверка выполнена в Chromium, настоящие Safari/Firefox и физические мобильные устройства отдельно не проверялись
Новые адаптеры требуют собственных проверок контента, сетевых зависимостей и поведения
