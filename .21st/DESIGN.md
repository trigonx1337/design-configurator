# Design Configurator

The studio uses the existing neutral light/dark tool palette, two panes and decision cards
Theme affects the shell only, site rendering belongs to a project adapter
Keep split resizing, isolated zoom, baseline comparison and portable export consistent across projects

The starter project is a quiet olive product page with real alternatives for colour, type, layout and density
The workshop project intentionally uses a different composition and demonstrates standalone runtime behaviour
Project-specific card thumbnails can be supplied through the optional preview adapter

No generated media or external UI packages are required
21st resizable metadata was considered, the existing implementation was retained to preserve portability
See PROJECT-GUIDE.md for adapter contracts and AGENTS.md for future project work
